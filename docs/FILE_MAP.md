# File map — Phase 1

All paths are relative to this independent mobile root. No future-phase placeholder files are created.

| Files | Ownership and behavior |
| --- | --- |
| `pubspec.yaml`, `pubspec.lock`, `analysis_options.yaml`, `l10n.yaml`, `.gitignore`, `.metadata` | Flutter dependencies, analysis, generation and platform metadata |
| `lib/main.dart` | Binding initialization and Riverpod root |
| `lib/app/app.dart` | Material app, persistent theme, localization and router |
| `lib/app/router/app_router.dart`, `route_names.dart` | All Phase 1 routes, retained tab branches and unknown-route recovery |
| `lib/app/theme/app_colors.dart`, `app_text_styles.dart`, `app_theme.dart` | Palette, typography, Material 3 component styles |
| `lib/app/l10n/app_en.arb`, `l10n.dart` | Centralized English copy and context accessor |
| `lib/app/l10n/generated/*` | Generated by Flutter; ignored and never edited manually |
| `lib/core/config/app_config.dart` | App identity, default marker size and reserved configurable API base URL |
| `lib/core/storage/app_preferences_store.dart` | Non-critical onboarding/theme persistence adapter and interface |
| `lib/core/widgets/app_button.dart`, `app_page.dart`, `empty_state.dart`, `error_view.dart`, `loading_view.dart`, `status_card.dart` | Reusable responsive UI, loading/error/empty/unavailable states |
| `lib/features/onboarding/presentation/pages/splash_page.dart`, `onboarding_page.dart` | Startup, retry, introduction, persistent guest entry |
| `lib/features/home/presentation/pages/home_page.dart` | Offline workspace and navigation shortcuts |
| `lib/features/home/presentation/widgets/stats_card.dart`, `recent_samples_card.dart` | Explicitly unavailable statistics/library until SQLite exists |
| `lib/features/capture/presentation/pages/capture_page.dart`, `end_capture_page.dart`, `side_capture_page.dart` | Two-view preparation and blocked capture |
| `lib/features/capture/presentation/widgets/capture_stepper.dart`, `capture_instructions.dart` | Workflow overview and shared positioning instructions |
| `lib/features/history/presentation/pages/history_page.dart` | Local-library availability and report/capture links |
| `lib/features/sync/presentation/pages/sync_page.dart` | Manual-only policy and disconnected cloud state |
| `lib/features/study/presentation/pages/study_page.dart` | Offline expandable capture and measurement guidance |
| `lib/features/settings/presentation/pages/settings_page.dart` | Persisted appearance, language/model status and settings navigation |
| `lib/features/settings/presentation/providers/preferences_provider.dart` | Serialized preference changes and retryable async state |
| `lib/features/profile/presentation/pages/profile_page.dart` | Local guest and optional account information |
| `lib/features/auth/presentation/pages/login_page.dart`, `register_page.dart` | Honest auth-service availability; no credential collection |
| `lib/features/calibration/presentation/pages/calibration_page.dart` | Marker-plane guidance, default size, uncalibrated status |
| `lib/features/reports/presentation/pages/reports_page.dart` | Reports unavailable until samples can be saved |
| `lib/shared/widgets/main_navigation_shell.dart` | Single reusable bottom navigation/rail shell |
| `lib/shared/widgets/quill_illustration.dart` | Original code-native cinnamon illustration, never a detection result |
| `assets/data/capture_checklist.json` | Machine-readable preparation checklist; no grades or model predictions |
| `test/support/test_app.dart` | Isolated preference adapter and widget harness |
| `test/settings/preferences_test.dart` | Serialization, overlapping updates and write failure recovery |
| `test/widgets/app_navigation_test.dart` | Onboarding, routes, tabs, offline/model/auth states, theme, errors and responsive UI |
| `integration_test/app_test.dart` | Real native preferences and five-tab navigation smoke test |
| `android/**` | Flutter-created Android host, launcher resources, Gradle wrapper/config and QuillGrade display name |
| `ios/**` | Flutter-created iOS host, Xcode project/assets and QuillGrade display name |
| `README.md`, `docs/*.md` | Setup, scope, contracts, prerequisites and validation results |

The IDE project files produced by `flutter create` and machine-specific build/configuration files are ignored. Add Drift-generated files beside their source when Phase 2 introduces Drift. Keep future OpenCV Kotlin/C++ code under the Android source tree.
