The IDE project files produced by `flutter create` and machine-specific build/configuration files are ignored. Drift-generated files live beside their source and are regenerated with build_runner. Keep future OpenCV Kotlin/C++ code under the Android source tree. See [PHASE_2_STORAGE.md](PHASE_2_STORAGE.md) for storage semantics, verification and limitations.

See [UI_STUDY_GUIDE.md](UI_STUDY_GUIDE.md) for the enhancement inventory and validation. No study photo directories are prefilled; add authorized grade-specific files under `assets/images/study/<group>/` only when supplied, register their assets, and record attribution in the JSON.
